#### 2.1 `engine/state_bridge.py` (NEW — critical missing piece)
This is the **bridge** that maps the simulation's market state to the 280-dim vector the PolicyNetwork expects. The original plan's 9-dim tensor is insufficient.

```python
"""
StateBridge: Maps simulation environment states → CPL-compatible 280-dim vectors.

The CPL PolicyNetwork expects: [GNN_emb(256) | cost(6) | perf(6) | health(8) | queues(4)] = 280
We synthesize these components from the MarketEnv + campaign outcomes.
"""

import torch
import numpy as np
from typing import Dict

class StateBridge:
    def __init__(self, gnn_dim: int = 256):
        self.gnn_dim = gnn_dim
    
    def encode(
        self,
        market_cpms: Dict[str, float],     # {'meta': 12.0, 'google': 8.0, 'tiktok': 6.0}
        competition: float,                 # 0-1
        trend: float,                       # -1 to 1
        day_of_week: int,                   # 0-6
        hour: int,                          # 0-23
        budget_remaining: float,
        spend_rate: float,
        conversions: int,
        revenue: float,
        roas: float,
        cac: float,
    ) -> torch.Tensor:
        """
        Produce a 280-dim state vector from simulation state.
        
        Component breakdown:
        - GNN embedding (256): Encoded from market topology + agent graph (learned projection)
        - Cost vector (6): [cpm_meta, cpm_google, cpm_tiktok, spend_rate, cac/30, competition*cost_factor]
        - Perf vector (6): [roas/5, conversions/100, revenue/500, budget_remaining/1000, 
                            market_trend, 1 - cac/30]
        - Agent health (8): Channel health indicators (meta_health, google_health, 
                            tiktok_health, budget_health, conversion_health, 
                            fatigue_health, competition_pressure, 0)
        - Queue depths (4): [impression_queue/1000, spend_queue/100, 
                             conversion_backlog/10, calibration_queue/1]
        """
        # GNN embedding: project market features through a learned linear layer
        # (In production, this would come from Neo4j graph; in simulation we synthesize)
        gnn_features = torch.tensor([
            *[market_cpms.get(ch, 0) / 20.0 for ch in ['meta', 'google', 'tiktok']],
            competition, trend, day_of_week / 6.0, hour / 23.0,
            budget_remaining / 1000.0, spend_rate / 100.0,
            conversions / 1000.0, revenue / 5000.0,
            roas / 10.0, cac / 50.0
        ], dtype=torch.float32)  # 13-dim input → project to 256
        
        # Simple learned projection (random init for simulation; GNN would replace this)
        if not hasattr(self, 'gnn_projection'):
            self.gnn_projection = torch.nn.Linear(gnn_features.shape[0], self.gnn_dim)
            # Don't train this in sim — it's a placeholder for the real GNN
        
        gnn_embedding = self.gnn_projection(gnn_features).detach()
        
        # Cost vector (6-dim) — matching CostGovernor expectations
        cost_vector = torch.tensor([
            market_cpms.get('meta', 0),           # GPU-equivalent: meta CPM
            market_cpms.get('google', 0),          # tokens cost: google CPM
            market_cpms.get('tiktok', 0),          # latency cost: tiktok CPM
            spend_rate,                             # memory cost: spend velocity
            cac / 30.0,                             # storage cost: normalized CAC
            competition * 10.0                      # network cost: competition pressure
        ], dtype=torch.float32)
        
        # Performance vector (6-dim)
        perf_vector = torch.tensor([
            roas / 5.0,                             # accuracy: ROAS normalized
            conversions / 1000.0,                   # revenue: conversions
            revenue / 5000.0,                       # success rate: revenue
            budget_remaining / 1000.0,              # throughput: budget fraction
            (trend + 1) / 2.0,                      # efficiency: market trend
            1.0 - min(cac / 30.0, 1.0)              # stability: inverse CAC
        ], dtype=torch.float32)
        
        # Agent health (8-dim) — channel viability indicators
        agent_health = torch.tensor([
            1.0 - min(market_cpms.get('meta', 0) / 24.0, 1.0),    # meta health
            1.0 - min(market_cpms.get('google', 0) / 24.0, 1.0),  # google health
            1.0 - min(market_cpms.get('tiktok', 0) / 24.0, 1.0),  # tiktok health
            budget_remaining / 1000.0,                              # budget health
            min(conversions / 100.0, 1.0),                         # conversion health
            1.0 - min(spend_rate / 500.0, 1.0),                    # fatigue health
            competition,                                             # competition pressure
            0.0                                                      # reserved
        ], dtype=torch.float32)
        
        # Queue depths (4-dim)
        queue_depths = torch.tensor([
            market_cpms.get('meta', 0) * spend_rate / 12000.0,    # GPU 0: meta load
            market_cpms.get('google', 0) * spend_rate / 8000.0,   # GPU 1: google load
            spend_rate / 500.0,                                     # CPU: spend queue
            (1.0 - min(roas / 5.0, 1.0))                           # Network: ROAS gap
        ], dtype=torch.float32)
        
        # Concatenate → 280-dim
        state = torch.cat([
            gnn_embedding,      # 256
            cost_vector,        # 6
            perf_vector,        # 6
            agent_health,      # 8
            queue_depths       # 4
        ])  # Total: 280
        
        return state
```

#### 2.3 `engine/training_loop.py` (NEW — referenced but never defined)

```python
"""
Training Loop: Runs the CPL PolicyNetwork inside the MarketEnv simulation
and produces Trajectory objects compatible with StreamingPPOTrainer.update().
"""

import torch
import logging
from typing import List, Optional
from dataclasses import dataclass, field
from datetime import datetime

@dataclass
class EpisodeResult:
    episode: int
    total_reward: float
    total_conversions: int
    total_spend: float
    final_roas: float
    trajectory_length: int
    states: List[torch.Tensor] = field(default_factory=list)
    actions: List[int] = field(default_factory=list)
    log_probs: List[float] = field(default_factory=list)
    rewards: List[float] = field(default_factory=list)
    values: List[float] = field(default_factory=list)
    costs: List[float] = field(default_factory=list)
    dones: List[bool] = field(default_factory=list)

class TrainingLoop:
    def __init__(self, policy_network, ppo_trainer, market_env, 
                 user_model, reward_engine, state_bridge, event_producer=None):
        self.policy = policy_network
        self.trainer = ppo_trainer
        self.env = market_env
        self.user_model = user_model
        self.reward_engine = reward_engine
        self.state_bridge = state_bridge
        self.event_producer = event_producer
        self.logger = logging.getLogger(__name__)
        self.trajectory_buffer = []
    
    async def run_episodes(self, n_episodes: int, budget: float, 
                           max_steps: int = 720) -> List[EpisodeResult]:
        """Run n training episodes, producing Trajectory objects for PPO updates."""
        results = []
        
        for ep in range(n_episodes):
            result = await self._run_single_episode(ep, budget, max_steps)
            results.append(result)
            
            # Accumulate trajectory and train when buffer fills
            self._accumulate_trajectory(result)
            if len(self.trajectory_buffer) >= 64:
                await self._train_on_buffer(budget)
            
            if self.event_producer:
                await self._publish_episode(result)
        
        return results
    
    async def _run_single_episode(self, ep: int, budget: float, max_steps: int):
        """Run one episode: env reset → policy loop → trajectory collection."""
        self.env.reset(initial_budget=budget)
        self.user_model.reset_fatigue()
        result = EpisodeResult(episode=ep, total_reward=0.0, total_conversions=0,
                               total_spend=0.0, final_roas=0.0, trajectory_length=0)
        
        for step in range(max_steps):
            # Get state in 280-dim
            state = self.env.to_tensor_280(self.state_bridge, 
                                           conversions=result.total_conversions,
                                           revenue=result.total_conversions * 50.0,
                                           roas=result.final_roas)
            
            # Policy selects action
            with torch.no_grad():
                action, log_prob, value, entropy = self.policy.get_action(state)
                cost_pred = self.policy.predict_cost(state.unsqueeze(0)).item()
            
            action_idx = action.item()
            
            # Map action to simulation action
            sim_action = self._map_action(action_idx, self.env.current_state)
            
            # Step environment
            next_market, _, done, info = self.env.step(sim_action)
            
            # Simulate user response
            impressions = {
                'meta': int(info['cpm_meta'] * sim_action['budget_allocation'] / 20),
                'google': int(info['cpm_google'] * sim_action['budget_allocation'] / 20),
                'tiktok': int(info['cpm_tiktok'] * sim_action['budget_allocation'] / 20)
            }
            conversions, _ = self.user_model.predict_conversions(impressions)
            outcome = self.reward_engine.compute_outcome(conversions, info['spend'])
            reward, metrics = self.reward_engine.compute_reward(
                outcome, {'cpm': info}, sim_action
            )
            
            # Store trajectory components
            result.states.append(state)
            result.actions.append(action_idx)
            result.log_probs.append(log_prob.item())
            result.rewards.append(reward)
            result.values.append(value.item())
            result.costs.append(cost_pred)
            result.dones.append(done)
            
            result.total_reward += reward
            result.total_conversions += conversions
            result.total_spend += info['spend']
            result.trajectory_length += 1
            
            if done:
                break
        
        if result.total_spend > 0:
            result.final_roas = (result.total_conversions * 50.0) / result.total_spend
        
        return result
    
    def _map_action(self, action_idx: int, market_state) -> dict:
        """Map CPL action (0-5) to simulation action."""
        actions = {
            0: {'budget_allocation': 50.0},       # spawn_agent → low spend
            1: {'budget_allocation': 0.0},         # kill_agent → stop spend
            2: {'budget_allocation': 150.0},       # route_task → high spend
            3: {'budget_allocation': 100.0},       # allocate_budget → normal spend
            4: {'budget_allocation': 75.0},        # adjust_temperature → medium-low
            5: {'budget_allocation': 200.0},       # prioritize_workflow → aggressive
        }
        base = actions.get(action_idx, {'budget_allocation': 100.0})
        base['channel_mix'] = {'meta': 0.4, 'google': 0.4, 'tiktok': 0.2}
        return base
    
    async def _train_on_buffer(self, budget: float):
        """Flush trajectory buffer to PPO trainer."""
        from services.cpl_service.engine.ppo_trainer import Trajectory
        traj = Trajectory(
            states=torch.stack(self.trajectory_buffer),
```

### Phase 5: Migration Strategy

**Goal:** Progressive rollout from simulation-only to full production.

#### Stage 1: Sim-Only Training (Week 1)
- PolicyNetwork trains exclusively on simulated data
- No real capital at risk
- All 6 actions exercised in market scenarios
- Checkpoint every 100 episodes
- Gate: Policy must achieve ROAS > 2.0 in simulation for 100 consecutive episodes

#### Stage 2: Shadow Mode (Week 2)
- Simulation service runs alongside real CPL service
- CPL uses its current policy (not sim-trained) for real actions
- Simulation produces shadow predictions for every real state
- Calibration data collected from `execution.outcome` Kafka topic
- Gate: `calibration_quality == 'good'` (168+ data points, MSE < threshold)

#### Stage 3: Hybrid — A/B Testing (Week 3)
- 10% of campaigns use sim-trained policy (candidate version)
- 90% use existing policy (active version)
- PolicyRegistry manages A/B split
- Automatic rollback if candidate underperforms by >10%
- Gate: Candidate ROAS exceeds active ROAS for 7 consecutive days

#### Stage 4: Full Deployment
- Candidate promoted to active
- Old policy retired
- Continuous sim training continues as backup
- Real execution outcomes feed back into sim calibration
