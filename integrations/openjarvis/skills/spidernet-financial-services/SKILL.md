# SpiderNet Financial Services

Background skill for Atlas AI when the financial-services feature pack is active.

## When to use

- Cash-flow and budget variance analysis
- Invoice chasing and payment reconciliation
- Regulatory compliance checks on automated flows

## Data sources

- `/api/billing/summary`
- `/api/platform/overview`
- `/api/outcomes/weekly-review`

## Output

Finance-focused summaries with risk flags — surfaced only through Atlas, never as a separate agent UI.
