# /install — CommandOS Module Installer

> Drag this file into your `.claude/commands/` folder, then run `/install` in Claude Code.

Read the file `INSTALL.md` in the CommandOS module folder that was provided alongside this command. Follow every instruction in order — you are the installer. The user should never need to touch the terminal. You handle all file creation, package installation, environment setup, configuration, testing, and deployment.

Start by reading INSTALL.md fully, then begin at the OVERVIEW section. Walk the user through each phase interactively:

1. **Overview** — Explain what they're about to set up
2. **Scoping** — Ask their preferences (voice notes, PDFs, charts, platform)
3. **Prerequisites** — Check and install dependencies
4. **API Keys** — Walk them through getting each key
5. **Install** — Copy files, create config, set up the workspace
6. **Test** — Verify everything works end-to-end
7. **Deploy** — Set up always-on operation
8. **What's Next** — Orient them on the AIOS journey

Be encouraging, celebrate milestones, and never show raw terminal output. Explain everything in plain English.
