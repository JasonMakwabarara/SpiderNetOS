# SpiderNetOS 3-1-90

Reverse-engineered from the future state, per `docs/internal/operating-model.md` — work backwards from where the project should be, not forwards from where it is today.

## 3-year target

SpiderNetOS is the default operating system a small business owner buys instead of stitching together a CRM, a scheduling tool, an email platform, and a part-time VA. Feature packs cover the common verticals (sales, real estate, financial services, compliance) and a marketplace lets third parties publish new ones against the documented `docs/feature-packs/SPEC.md` contract.

## 1-year target

- Feature Pack registry REST API is live (roadmap Phase 3 item currently marked "Planned") with real signature verification (not the current structural-only check — see `docs/internal/awareness-list.md`).
- Cross-tenant learning (roadmap Phase 4) is live for at least one pack, with the privacy-preserving aggregation the roadmap already specifies.
- At least two packs (sales-crm, real-estate-crm) have a purchase → discovery interview → owner-approved artifact → go-live pipeline, proven out first by the Lead-to-Sale Funnel bundle.

## 90-day target (current cycle)

**Asset:** the Lead-to-Sale Funnel bundle (`packages/feature-packs/sales-crm/`) — discovery interview, owner-approved sales script, email + WhatsApp channels, Dodo Payments purchase flow, and the Five A's operating rhythm productized for tenants.

Success criteria for this cycle:
- A tenant can purchase the bundle, complete the interview, approve a script, and have the funnel capture/qualify/follow-up a lead end to end without engineering involvement.
- `FunnelSetupService`'s pipeline and the Dodo webhook flow are covered by regression tests (`tests/Feature/Sales/`, `tests/Unit/Payments/`) — done, pending a Postgres+pgvector CI run to go green (see awareness list).
- Owner role, growth/CRM/retention roles, and open awareness items are visible in one place (`/operating`).

Next 90-day cycle candidates (not yet committed): WhatsApp template pre-approval for autonomous sends, per-tenant WhatsApp number provisioning at scale, a real financial-services integration for CAC:LTV in the scoreboard.
